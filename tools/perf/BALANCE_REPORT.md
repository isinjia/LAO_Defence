# 밸런스 리포트 — 80웨이브 (v31)

## 목표
- 최대 웨이브 80. 칸(18칸)이 성장을 막지 않을 것.
- 숙련자(smart) 승률: 쉬움 95% 안팎 / 보통 70~85% / 어려움 25~40%.
- AUTO는 숙련자보다 확실히 낮게. 입문자는 쉬움에서 40웨이브 이상.
- 리뷰 점수 추이:

| 차수 | 1차 | 2차 | 3차 | 4차 |
|---|---|---|---|---|
| 밸런스 / 재미 | 58 / 55 | 76 / 70 | 86 / 80 | 90 / 83 |

**5차(최종) 리뷰: 밸런스 90 / 재미 86.** 리포트의 수치는 모두 확인됐다. 리뷰어가 정정한 두 가지:
- 일일 작전은 스트림을 분리했지만 재시작해서 미리 정찰하는 것은 가능하다.
- 쉬움에서는 AUTO(100%)가 smart(93%)보다 높다.

## 4차 리뷰 지적 반영

| # | 지적 | 반영 |
|---|---|---|
| 1 | 20웨이브 벽과 초반 체력 급등 | 1~25웨이브 일반 체력을 로그 공간에서 균일화했다(절벽 없음, 웨이브당 +35~40% 일정). 20웨이브 보스 −15%(10→20 배율 ×40 → ×34). **12웨이브까지 강화를 하나도 안 했으면** 안내 토스트를 띄우고 강화 버튼을 강조한다 |
| 2 | 보통 승률이 목표 하한 | 보통 smart **77%**(30판, 59–88). 45웨이브 이후 일반 −12%, 50웨이브 이후 보스 −10% |
| 3 | 확률 보정이 숨겨짐 | 소환 확률 칸에 **"S급 보장까지 n회"** 와 **"재료 보정 35%"**(해당될 때)를 표시한다(ui.js odds) |
| 4 | 일일 작전 조작 가능 | 소환·합성·도박·보상·교체·AUTO 무작위의 난수 스트림을 **용도별로 분리**했다(`makeStreams`). 결과 화면에 **결과 복사**(모드·웨이브·별·시간·처치) |
| 5 | 사람이 직접 하는 순간 결정 | **집중 공격**: 적을 탭하면 조준 마커가 붙고, 사거리 안 모든 유닛이 그 적을 먼저 공격한다(우선순위: 현재 보스 > 집중 대상 > 엘리트, 다시 탭하면 해제). AUTO는 하지 않는다 |
| 5 | 수동 궁극기 보상 | 사용자 결정으로 넣지 않음: 수동과 자동은 위력이 같고, 수동은 타이밍 선택용 |
| 재미 2 | 쉬움에 목표 긴장이 없음 | 쉬움의 별 2·3개 조건을 **최대 적 60·30 미만**으로 바꿨다 |
| 재미 4 | 변이 반복감 | 변이 5종: 고속 / 장갑 / 분열 / **재생**(1.5초 무피격 시 초당 3%) / **원거리 저항**(원거리 −25%, 근접 +30%) |

**6차 리뷰(v31): 밸런스 91 / 재미 87.** 남은 지적:
- 어려움이 목표보다 쉽다(제안: 어려움 후반 배수 1.38).
- 입문자 구간이 후퇴했다(제안: 쉬움 후반 배수 0.55).
- 61~70웨이브가 과밀하다(변이 63·67웨이브 완화).
- 측정 버전이 섞여 있다. 보통·쉬움·입문자는 v30 측정이고, v31은 어려움 배수만 바꿨으므로 v30 결과도 유효하다.
- 사람 플레이 테스트가 없다.

## 5차 리뷰 이후 보강 (v30~v31)

| 지적 | 반영 |
|---|---|
| 모바일에서 확률 공개가 숨겨짐 | 소환 버튼 오른쪽 위에 **"S n"**(S급 보장까지 남은 횟수)과, 재료 보정이 걸리면 **"+35%"** 배지를 띄운다. 화면 폭과 상관없이 보인다 |
| 후반 긴장이 보스 한 축에 몰림 | 56웨이브 이후 일반 체력 **+3%/웨이브**(이전 +1~2%), 60·70·80웨이브 보스 −15%. 보스/일반 비율 60·70·80웨이브: 22·36·47배 → **19·27·30배** |
| AUTO와 숙련자 격차 | 보통 smart 70% vs AUTO 27%로 **신뢰구간이 다시 겹치지 않음**. 쉬움에서도 AUTO(67%)가 smart(93%)보다 낮아졌다 |
| 집중 공격이 보스를 가림 | 우선순위를 현재 보스 > 집중 대상 > 엘리트로 바꿨다 |
| 어려움 | 후반 일반 체력이 늘어난 만큼 어려움 배수를 ×1.1→1.5에서 **×1.1→1.3**으로 낮췄다(×1.5에서는 smart 0/15) |

## 측정 도구 (`tools/lab/`)
- `balance.js`
  - `evaluate`: 시드 고정 + 렌더링 끄기 + MessageChannel 진행
  - `autotune`: 닫힌 루프 조정. 최소 기울기 +1%/웨이브를 지킨다
  - 봇: `smart` / `auto` / `novice` / `casual` / `smartAutoUlt`
- `headless.py`: 헤드리스 Chrome 병렬 측정(20초 간격 실행, 로딩이 멈추면 다시 불러옴). 앱 패널이 숨겨지면 측정이 멈추므로 어려움은 이것으로 쟀다. `merge.py`로 묶음을 합친다.
- 집계: `python tools/lab/balance_report.py <tag>` (95% Wilson 신뢰구간 포함).

## 알려진 한계
- 사람 플레이 테스트가 없다. 리뷰어 기준으로 95점 이상은 사람 테스트(사람 승률이 smart와 novice 사이인지, "한 판 더" 의향)가 있어야 근거가 된다. 이번 작업은 이 선에서 마무리한다.
- 1~25웨이브 일반 체력 증가가 웨이브당 35~40%다. 합성 ×4 성장에 맞춘 값으로, 균일하지만 30%를 넘는다.
- 상세 확률 칸은 1100px 이하에서 숨겨진다. 소환 버튼 배지(보장 횟수·재료 보정)로 대신한다.
- 보통 smart 70%는 목표 범위(70~85%)의 하한이다. 어려움 50%는 상한보다 약간 높다.
- 입문자 × 보통은 중앙값 36웨이브다. 입문자에게는 쉬움을 권하는 설계다.
- 집중 공격과 12웨이브 강화 안내는 봇이 쓰지 않아 효과가 측정되지 않았다.

## 버전 이력
- **v1~v25:** 1~4차 리뷰(이전 리포트 참고).
- **v26:** 4차 지적 반영 직후. 보통 smart 52%(50판)로 너무 어려움.
- **v27:** 59~69웨이브 +10%를 되돌리고 보스 50·60을 하향. 보통 smart 55%.
- **v28:** 변이 2종 완화. 보통 smart 53%.
- **v29:** 45웨이브 이후 일반 −12%, 50웨이브 이후 보스 −10%. 5차 리뷰 90/86.
- **v30:** 후반 일반 +3%/웨이브, 후반 보스 −15%, 소환 버튼 확률 배지, 집중 공격 우선순위 수정. 보통 70% / AUTO 27%. 어려움(×1.5)은 0%.
- **v31:** 어려움 후반 배수 1.5 → 1.3. 어려움 smart 50% / AUTO 20%. 위 결과.
